# 🚀 FINORA AI - LIVE WORKING WEBSITE

## INSTANT START (Copy-Paste Commands)

### **STEP 1: Open Terminal/Command Prompt**

Copy and paste this ONE command:

```bash
git clone https://github.com/Suryansh-X/fintech-llm-automation.git && cd fintech-llm-automation && npm install && cd client && npm install && cd ..
```

### **STEP 2: Create .env File**

Create a file named `.env` in the root folder with this content:

```
PORT=5000
NODE_ENV=development
OPENAI_API_KEY=sk-put-your-key-here
JWT_SECRET=mysecurekey12345
FRONTEND_URL=http://localhost:5173
DB_HOST=localhost
DB_PORT=5432
DB_NAME=fintech_llm
DB_USER=postgres
DB_PASSWORD=postgres
```

**Get OpenAI Key:**
1. Go to https://platform.openai.com/api-keys
2. Create new secret key
3. Copy and paste in .env

### **STEP 3: Start Everything**

```bash
npm run dev
```

### **STEP 4: Open Browser**

```
http://localhost:5173
```

**DONE! Website is running!** ✅

## 🆘 Quick Fixes

**"npm not found?"**
→ Install Node.js: https://nodejs.org/

**"Port in use?"**
→ Change PORT in .env to 5001

**"API key error?"**
→ Check key at https://platform.openai.com/account/billing/

**"Nothing working?"**
→ Delete node_modules, run `npm install` again
